# aydin's Kitchen

Website katalog kue rumahan dan pemesanan WhatsApp untuk aydin's Kitchen (Gambut, Kab. Banjar, Kalimantan Selatan).

Spesialis:
* Brownies Panggang Fudgy
* Bento Cake Custom
* Kue Kering
* Dessert Box

## Tech Stack

* Astro 5
* Tailwind CSS v4
* Fraunces & Plus Jakarta Sans Typography

## Jalankan Project

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```
